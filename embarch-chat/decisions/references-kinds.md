# embarch-chat decisions: The linker's kinds

**Status:** active, 2026-11-25.

What each kind the linker takes is, one decision each (112's sources): branches and worktrees, the atlas's sections, symbols and nodes, the bench's instruments. Split verbatim from [references.md](references.md), which holds the desk's index (88) and the linker's shape (112).

Index: [../decisions.md](../decisions.md). Current truth: [../spec.md](../spec.md).

### 113 — The linker offers the chat folder's branches and worktrees

**Decided 2026-11-25** (`embarch-promptu` decision 16, build step 5; contract 15.2's `branch` and `worktree` rows; EMB-410; the first kind added as 112 says, `src/assistant/refsGit.ts`). **One source, read from git in the chat folder's main clone**: `git for-each-ref --sort=-committerdate --count=300` over `refs/heads` and `refs/remotes/origin`, a remote branch with a local twin once, `origin/HEAD` none; and `git worktree list --porcelain`, each with its path and branch (`deskService.ts`'s `git`, `mainRepo` and worktree read, shared). **Gated**: by words only when the draft carries branch, worktree, checkout, clone, rebase or merge (whole word, any case); a branch name or worktree path the draft names exactly is offered with none (112). An entry's words are its name split on `/`, `-`, `_` and `.`; a worktree's also its folder's. **Written**: `branch <name>`, plus ` (PR owner/repo#N)` when the desk's index holds a PR on that branch (the chat's own repo's first); `worktree <absolute path> (branch <name>)`. **The chat's own branch and worktree are left out**, as 88 leaves out its own item; a name or path that would change if cleaned (an unseen character, `<`, `>`, past 200 characters) is not offered rather than offered cut. **Refresh**: before a cards call, only when the folder's last read is over 60 s old, so git runs at most once a minute while drafts change, and never for ghost text or a keystroke (26); a read that fails leaves both kinds empty, is not retried inside the minute, and logs once per folder. **Assumed, not measured:** the 300 cap, the cue words and the 60 s are `embarch-promptu`'s recommendations, which the owner may strike. A bare `main` the draft names offers the branch with no cue word, as 112 has an exact name do. **Not seen against a real window**; tested on scratch repos. **Rejected:** a git read per keystroke, a branch offered without a gate (every draft with "main" or "fix" would show it), the PR's title on a branch line (the branch is what is written).

### 114 — The linker offers the atlas's datasheet and spec sections

**Decided 2026-11-25** (`embarch-promptu` decision 16, build step 5; contract 15.2's `section` row; EMB-411; the second kind added as 112 says, `src/assistant/refsAtlas.ts`; amends 16 not at all: it adds no prose link). **One source, read with `embarch-atlas refs --json`** (`atlas_refs`, `atlas/109`) in the chat's folder: one entry per section of every translated document, its words the title's and the id's, naming its document's `doc_id` and `part`; the binary is the new `embarchChat.atlasPath` setting, `embarch-atlas` on PATH by default. **Gated**: by words only when the draft carries datasheet, spec, specification, standard, section, chapter, table, manual, errata or app note (whole word, any case), or names a document's part, which opens that document's sections alone; those cue words are left out of an entry's own words, so "datasheet" matches no title. **Written** `<doc_id> p<page> §<id> "<title>"`: the `<doc_id> p<N>` head is the shape 16's links match, so the same text is a citation link wherever the chat finds the atlas; a section with no page, a page past 9999 or an id that cleaning would change is not offered. **Refresh**: a stat of the atlas's `current.json`, `atlases/` and `docs/` before a cards call, and the verb runs only when one moved (or the binary did), so two cards calls with no change spawn it once; 10 s limit. No binary, no atlas or a failed run leaves the kind empty and logs once per cause. **Assumed, not measured:** the cue words, the 10 s limit and the change-stat refresh are the plan's recommendations (choices 11, 12, 14, 15), which the owner may strike; the 20,000-section cap is this unit's. A change inside one document's folder that leaves `docs/`'s own mtime alone is not seen until something else moves. **Not seen against a real atlas**; tested on a fake `embarch-atlas` (`test/fake-atlas.mjs`). **Rejected:** a verb run per cards call, a prose link of its own (16 stands), the verb's symbols and nodes here (EMB-412 shares this read).

### 115 — The linker offers the atlas's Kconfig symbols and devicetree nodes

**Decided 2026-11-25** (`embarch-promptu` decision 16, build step 5; contract 15.2's `symbol` and `node` rows; EMB-412; the third and fourth kinds, `src/assistant/refsAtlas.ts`). **Two kinds from 114's read, no second run of `embarch-atlas`**: the same `refs --json` document's `symbols` and `nodes`, kept whole per folder and re-read only when the atlas changed. **Atlas only** (plan choice 4): a repo with no built atlas (`atlas` null) offers neither, its translated documents still offering sections. **Symbols**: words from the prompt; named `CONFIG_<NAME>`, or the bare `<NAME>` when the draft writes it in capitals with an underscore. **Gated** (plan choice 11) on kconfig, config, option, symbol, setting, `prj.conf`, menuconfig, or an exact name. **Written** (plan choice 12) `CONFIG_<NAME> ("<prompt>")`, no value, since the atlas's is its commit's. **Nodes**: words from the labels, the node's name (the path's last part, unit address dropped) and the compatibles split on `,` and `-`; named `&<label>`, a label, an alias or a path. Gated on devicetree, DT, node, overlay, DTS, binding, compatible, alias, chosen, or an exact name. Written `&<label> (<path>, <compatible>)`, the path alone with no label. The cue words are left out of an entry's own words, as 114 does. **A stale atlas** (`stale` not empty) still offers, and the entry's `note`, "the atlas is at an older commit", is added to the card's why by the extension after the model's (`parseCards`), not left to Haiku. **Assumed, not measured:** plan choices 4, 11 and 12 and the cue words are the plan's recommendations, **the owner's to strike**. A node with several labels is written with its first clean one; a symbol with no prompt has no words and is found by name only. **Not seen against a real atlas**; tested on the fake `embarch-atlas`. **Rejected:** the symbol's value in the line (it is the atlas commit's, not the repo's), a second read per kind, the model writing the stale warning.

### 116 — The linker offers the bench's declared instruments

**Decided 2026-11-25** (`embarch-promptu` decision 16, build step 5; EMB-414; the fifth kind added as 112 says, `src/assistant/refsInstruments.ts`, over a runner of its own, `src/assistant/apiRun.ts`). "Set the load to 1 A and read the supply" names instruments Core knows by name and the chat cannot see: it has no Core client (15), but it finds the `embarch-api` binary as Promptu's `--have` does (`findBinary`, `embarch-promptu` decision 36). **A runner for `embarch-api --json <verb>`**, separate from the source so a later kind reuses it: run in the chat's folder, where the verb finds `embarch/embarch.toml` upward as every verb does; a 10 s limit; the answer, or the failure, kept 5 minutes per folder and verb; run only before a cards call of the chat on screen (never for ghost text or a keystroke, 26), so cards calls inside the five minutes spawn it once. No binary: no spawn and no log. No config, Core unreachable, a non-zero exit or output that is not JSON leaves the kind empty and logs once per cause. **One source**, from `list-instruments` over Core's lease-open `GET /instruments`: no lease and no hardware, a list read. A declaration holds a `name` and a `protocol` and nothing a draft could be matched on, so the source has no words: **a draft that carries instrument, supply, PSU, load, meter, multimeter, DMM, scope, oscilloscope, analyzer or SMU (whole word, any case) is offered every declared instrument**, and a draft that names one offers it with no cue word (112's exact name). **Written** `instrument "<name>" (<protocol>)`; a name or protocol that cleaning would change, or one past 60 characters, is not offered rather than offered cut. **Assumed, not measured, the owner's to strike:** the runner's existence, the 10 s and 5 minute figures, the word list and the written form. **Not seen against a real bench**; tested on a fake `embarch-api` (`test/fake-api.mjs`), never a live Core. **Rejected:** a Core client in the chat (15), the verb run per cards call, matching an instrument's name against the draft's words (a name like `psu` says what it is, `eload` does not), an `embarchChat` setting for the binary (it is found on PATH, as Promptu's is).
