# embarch-promptu: read-only session commands

**Status:** active, 2026-11-23.

Moved verbatim from [spec.md](../spec.md) §2 (the last bullet too, 2026-11-23).

- **`promptu calls <session> [--subagent <id>] [--class <name>] [--json]`**: a recorded session's tool calls and result characters, per subagent (and the main thread) and per activity class (`git`, `build`, `config`, `source`, `other`), so a before/after replay is a measurement; with `--class`, that class's calls one per line with their result sizes. The class rules are one table in `src/calls.rs` (`classify`), pinned by a test. Reads Claude Code's transcripts; synthetic fixtures only in tests.
- **`promptu prior <prompt-file> [--projects <dir>] [--json]`** (EMB-185): what the earlier runs of a prompt asked and were answered. A transcript matches when its first user turn is the prompt (text equal after trimming; a footer-only file matches a first turn ending in that footer; the footer has no run id, so the text decides); the same footer under other text is a near-match, counted, not listed. Lists each session's `AskUserQuestion` calls with the `tool_result` that answered them. Read-only, one folder, `src/prior.rs` on `used.rs`'s reader. Contract §13.
- **`promptu week status`, `week show` and `desk`** (EMB-275, contract §9, §14.4): read-only views of the week folder, no model, no network, and nothing written. `status` gives the last run, the next, a missed or running one and the waiting sheet's open count, from the schedule key and the run records, never the scheduler; `show` prints a sheet; `desk` prints `{"promptu": 1, "open": 0}` when nothing is open, also with no state folder. `PROMPTU_NOW` pins the clock for tests; `running` rests on fork W12.
- **`promptu week pack`'s session events** (EMB-274, contract §14.5): from the transcripts alone, no model, no network, no `git`. Per session in the window: friction candidates (an interrupt then a real prompt, a rejected plan, a negation) with the follow-up text, whether it started with Promptu, an `unmatched` event for a long task start with no footer or `none`, an `outcome` for a `git commit` in the session or a subagent, and `carried` events for the earlier open sheet's open and failed lines. Fork W16; the phrase and nudge lists are `[assumed]`.
