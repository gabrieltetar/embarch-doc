### 132 - One confined writer for the person's `embarch/`, `embarch_api::person_writer`, ahead of any command that uses it

`ConfinedWriter::open(repo_root)` refuses when `<repo>/embarch` is a link or not a folder; `write(kind, name, bytes)` writes one file and returns its path below `embarch/`. **The rule:** only under `embarch/`; a kind from a fixed set, each with one folder and one extension; a name from `[a-z0-9][a-z0-9._-]{0,99}` with no `..`, the extension appended by the writer; no link followed at any step (`openat` with `O_NOFOLLOW` from the `embarch` handle on Unix; on Windows `symlink_metadata` refusing a link or reparse point before each step); an existing target that is not a plain file, or has more than one hard link, refused; the file written to a `.tmp-<pid>-<n>` file in its folder, synced, then renamed over the target; nothing run, with no process start in the module, which a test checks by reading the module's own source. Folders are created as needed, never through a link.

**Kinds, settled here** (the task left the extensions and the study folder to the worker): `study` `studies/<name>.study.json`; `host_study` `studies/<name>.host-study.json`; `test_results` `tests/<name>.results.json`; `saved_bench` `topologies/<name>.toml`; `atlas_measured` `atlas/<name>.json`; `live_log` `live/<name>.jsonl` (the ledger's `<date>-<session>` stem is a valid name). **A study's own folder is `studies/<study>/`**, beside its flat file: `report_typ` takes the study's name and writes the fixed `studies/<study>/report.typ`; `prose` takes `<study>/<run>` and writes `studies/<study>/runs/<run>.md`, one file per run as [HIL 02](../../notes/hil/02-study.md) has it. The two compound forms are the only names with a `/`. **Extended by `api/197`:** `hil_repo` writes the layout of [134](test-plans.md) through this writer, so `test` (`<suite>/<id>` to `tests/suites/<suite>/<id>/test.json`), `test_study` (`<suite>/<id>/<file>`, beside it), `suite` (`tests/suites/<suite>/suite.json`) and `plan` (`tests/plans/<plan>.json`) replace the `.test.toml` kinds, which nothing wrote; `write_with(.., overwrite)` also refuses an existing file and says whether it replaced one, for a saved bench, which is never overwritten.

**These kinds and this name set are plan choice 3's recommendation** ([HIL 14](../../notes/hil/14-implementation-plan.md)), which the owner may strike; the writer is the module's own, so a struck kind is one enum arm. The person's mirror (C.17, `embarch-api person mirror`) is the only caller planned; any later writer into the person's `embarch/` goes through this one. **Not verified:** Unix only, by unit tests with one fixture per refusal; the Windows branch has not been built or run (`tasks/api/193`).
