# embarch-desk: draft-revision and desk-note routes

**Status:** active, 2026-11-24. Split out of [../interfaces.md](../interfaces.md) verbatim when that file left its reserve for the Promptu routes (EMB-282); nothing restated.

| Route | What |
|---|---|
| `GET /drafts/{id}`; `POST /drafts/{id}/revise` | EMB-165. `GET` is a draft in any state with `agent_body` (the agent's version, set at creation, moved only by a revision, never by `PATCH`) and `owner_diff` (`- `/`+ ` lines of the body against it), `owner_edited`. EMB-211: `versions`, `[{n, by: agent|owner, at_ms, text}]`, oldest first (version 1 the draft as made; one more per revision and per owner `PATCH` that changes the body; capped at 50, keeping version 1; a draft stored earlier gets one synthesized; for `github_replies` the replies as one text, EMB-212). `?from=&to=` (version numbers; `to` defaults to the latest, `from` to the one before `to`) adds `version_diff {from, to, diff}`; an unknown version is 404. `POST {section?, text}` replaces what sits under a heading (found case-insensitively outside code fences, running to the next heading of the same or higher level; the heading stays) or, with no `section`, appends. It applies to `agent_body` and, if the owner's body still holds that section as the agent wrote it, to the body; else 409 naming the section and both texts, nothing changed. A section the agent's version lacks or repeats is 400; a draft not open, 404; a `github_replies` draft takes `{comment_id, text}` instead and replaces that one reply (its `agent_body` kept beside the owner's text): 409 naming the reply and both texts if the owner edited it, 409 if it is posted, 400 with no `comment_id` or one the draft lacks |
| `GET`/`POST /desks/{id}/notes`, `PATCH`/`DELETE /desks/{id}/notes/{nid}`; `POST /sessions/{sid}/desk-note` | A desk's standing notes (74), oldest first. A note is `{id, text, source, session_id, created_ms, updated_ms}`: `id` `kn<N>`, `source` `user` or `agent`, `session_id` only on an agent's, `text` kept with `\n` line endings, no blank line and no trailing blanks. `GET` → `{"notes","used_chars","max_chars":4000,"max_note_chars":500}`; `POST {"text"}` → `201 {"note"}`; `PATCH {"text"}` → `{"note"}`; `DELETE` → `204`. Both limits count a note as a session hears it: a note's text with each line break counting 3 against 500, and `used_chars` its `- `, that text, ` (added by an agent)` on an agent's and a line break, against 4,000. The session route is `desk_add_desk_note`'s: `201 {"desk_id","note"}` on the desk whose notes the session's last start gave it, else the one it belongs to now, its folder's else its item's; 404 for a session never seen, 400 for a hidden or path-ignored one and for one with no desk. Empty text or a limit passed is 400 and stores nothing; an unknown desk or note, 404. `GET /view` carries the viewed desk's as `desk_notes`, the same shape plus `desk_id`, null with none open; `GET /sessions/{sid}` gains `desk_id` and `desk_notes`, the session's desk as the route picks it |
